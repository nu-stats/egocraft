# Example study

`sample-egos.csv`, `sample-alters.csv` and `sample-ties.csv` are a made-up
study (200 people in two survey waves, with the people they named and who knows
whom among them). No real person is in them: every value was generated by
`app/scripts/write-examples.ts` from the code in `app/src/sample/sample.ts`.

They are free to use for anything, without asking or citing (CC0 1.0,
public domain dedication: https://creativecommons.org/publicdomain/zero/1.0/).
The same study opens from **Try it** on EgoCraft's start screen.

Public data sets with network modules (for example the General Social
Survey's) are not included; check each one's terms before sharing it.
