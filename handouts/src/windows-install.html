Installing EgoCraft on Windows 11

How to install it, get past Windows' first warning, and try it out. It takes about five minutes, and you don't need to be an administrator.

Installing

1

Get the file

You need EgoCraft-windows-setup.exe. If you were sent egocraft.zip, right-click it in your Downloads folder, choose Extract All…, then Extract. The installer and this guide are inside.

If Edge says the file "isn't commonly downloaded", click … next to it, then Keep, then Show more ▸ Keep anyway. EgoCraft needs Windows 10 or 11 (64-bit); nothing else needs installing first.

2

Run the installer

Double-click EgoCraft-windows-setup.exe. Because EgoCraft isn't signed yet, Windows may first show a blue box saying Windows protected your PC:

  • Click More info.
  • Check that it names EgoCraft, then click Run anyway.

Click Next through the installer; the folder it suggests is fine. EgoCraft is installed for you alone, in your own user folder, so Windows doesn't ask for an administrator password. On the last page, tick Create desktop shortcut if you want one, leave Run EgoCraft ticked, and click Finish.

You only do this once. From then on, open EgoCraft from the Start menu like any other app.

Trying it

Start with the sample study

Click Open the sample study: a made-up study of 200 people in two waves, with egos, alters and the ties between them, so every screen has something in it. Use the steps on the left (Checks, Data, Sociograms, Measures, Results) to walk through it.

Your own study

  • Click Start a new study, then choose your ego, alter and tie files on Import, or drag them onto the boxes. CSV, Excel, Stata, SPSS and R files all work, as do exports from Network Canvas, EgoWeb, EgoNet and E-Net.
  • On Results, Save the results (ZIP) saves one row per ego with the codebook, and the Stata do-file and R script buttons save the code that reproduces every number.
  • Saved files go to your Downloads folder, and EgoCraft says where each one went.

Where your studies are kept

The open study is kept inside the EgoCraft app on this computer, so it is still there next time. That is separate from EgoCraft in a web browser, on an iPad or in Pinokio: to bring a study across, use Save as a file there and Open a study file here.

Use Save as a file now and then to keep a copy (.egocraft) you can back up or share. Everything stays on this computer: EgoCraft sends nothing anywhere.

If something goes wrong

"Smart App Control blocked an app that may be unsafe"

Some Windows 11 computers have Smart App Control turned on, and it blocks unsigned apps with no Run anyway button. Don't turn it off for EgoCraft. Use the web version instead: open nu-stats.github.io/egocraft in Edge. It is the same app, keeps your studies in the browser, and works offline once opened. Your IT department may also be able to allow the installer.

The window opens blank

EgoCraft draws its window with Microsoft Edge WebView2, which is part of Windows 11. On an older or trimmed-down Windows, install the WebView2 Runtime from Microsoft's website, then open EgoCraft again.

Removing it

Save any study you want to keep as a file first. Then open Start ▸ Settings ▸ Apps ▸ Installed apps, find EgoCraft, click … and choose Uninstall.

What to send back

  • Did the installer run after Run anyway, or did Smart App Control block it?
  • Your Windows version (Start ▸ Settings ▸ System ▸ About).
  • Whether dragging files onto Import worked, and whether saved files landed in Downloads.
  • Screenshots of anything odd or confusing.
