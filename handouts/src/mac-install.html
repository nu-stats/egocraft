Installing EgoCraft on a Mac

How to pick the right copy, install it, open it the first time, and try it out. It takes about five minutes.

Installing

1

Check which kind of Mac you have

Open the Apple menu and choose About This Mac. Look at the line called Chip or Processor:

It says Apple M1, M2, M3, M4 or laterYou need EgoCraft-mac-apple-silicon.dmg
It says IntelYou need EgoCraft-mac-intel.dmg

EgoCraft needs macOS 11 (Big Sur) or later. Nothing else needs installing first: no browser, Node or terminal.

2

Get the file

If you were sent egocraft.zip, double-click it in your Downloads folder to unzip it. Inside are both disk images and this guide. Keep the one that matches your Mac.

Otherwise, download it from github.com/nu-stats/egocraft/releases, under Assets for the latest version.

3

Copy EgoCraft to Applications

Double-click the .dmg. A window opens with the EgoCraft app and an Applications folder. Drag EgoCraft onto Applications.

Then eject the EgoCraft disk: click the eject symbol next to it in Finder's sidebar.

4

Open it the first time

Open Applications and double-click EgoCraft. Because EgoCraft isn't signed by Apple yet, macOS stops it the first time and says Apple could not check it. Click Done (or OK). Then:

  • Open Apple menu ▸ System Settings ▸ Privacy & Security.
  • Scroll down to Security. You'll see a line saying EgoCraft was blocked. Click Open Anyway.
  • Enter your Mac's password if asked, then click Open Anyway once more.
You only do this once. From then on EgoCraft opens like any other app.

Trying it

Start with the sample study

Click Open the sample study: a made-up study of 200 people in two waves, with egos, alters and the ties between them, so every screen has something in it. Use the steps on the left (Checks, Data, Sociograms, Measures, Results) to walk through it.

Your own study

  • Click Start a new study, then choose your ego, alter and tie files on Import, or drag them onto the boxes. CSV, Excel, Stata, SPSS and R files all work, as do exports from Network Canvas, EgoWeb, EgoNet and E-Net.
  • On Results, Save the results (ZIP) saves one row per ego with the codebook, and the Stata do-file and R script buttons save the code that reproduces every number.
  • Saved files go to your Downloads folder, and EgoCraft says where each one went.

Where your studies are kept

The open study is kept inside the EgoCraft app on this Mac, so it is still there next time. That is separate from EgoCraft in a web browser, on an iPad or in Pinokio: to bring a study across, use Save as a file there and Open a study file here.

Use Save as a file now and then to keep a copy (.egocraft) you can back up or share. Everything stays on this Mac: EgoCraft sends nothing anywhere.

If something goes wrong

macOS says EgoCraft is damaged and can't be opened

This message can appear for apps downloaded from the internet that aren't signed by Apple. EgoCraft isn't damaged. Open Terminal (in Applications ▸ Utilities), paste this line, press Return, then open EgoCraft again:

xattr -dr com.apple.quarantine /Applications/EgoCraft.app

"You can't open the application" or it closes at once

Check that you took the copy for your kind of Mac (step 1). An Intel copy on an Apple chip asks to install Rosetta; an Apple silicon copy does not open on an Intel Mac.

Removing it

Save any study you want to keep as a file first. Then drag EgoCraft from Applications to the Trash.

What to send back

  • Did it open after Open Anyway, or did macOS call it damaged?
  • Your Mac's chip and macOS version.
  • Whether dragging files onto Import worked, and whether saved files landed in Downloads.
  • Screenshots of anything odd or confusing.
